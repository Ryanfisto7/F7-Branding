## 3. SEO Discussion Questions & Answers
1. *Why are meta descriptions important for e-commerce sites?*
   They provide concise summaries of page content in search engine results pages (SERPs), improving click-through rates (CTR) and user engagement.
2. *How does image alt text benefit website accessibility?*
   Alt attributes allow screen readers to describe visual assets to visually impaired users and provide context if images fail to load.
3. *What is the purpose of the robots.txt file?*
   It instructs the search engine web crawlers which pages or files they are allowed or disallowed to request from the site.
4. *Why are descriptive title tags critical for SEO?*
   They act as the primary anchor for search engines to understand the exact topic of a web page and heavily influence ranking positions.
5. *How do XML sitemaps assist search engines?*
   They provide an organized structural map of all public URLs on a website, ensuring faster and more comprehensive indexing by web scrapers.
